# セキュリティポリシー（抜粋）

Acme AI Corp の情報セキュリティに関する遵守事項。

## 認証情報・シークレットの管理

APIキー・パスワード・トークン等のシークレットは、**Gitにコミットしてはならない**。
シークレットは Secrets Manager で一元管理し、アプリには環境変数経由で注入する。
誤ってコミットした場合は、直ちに該当キーを失効（ローテーション）し、セキュリティ担当へ報告する。

## パスワードと多要素認証

パスワードは**12文字以上**とし、社内システムでは**多要素認証（MFA）を必須**とする。

## 顧客データの取り扱い

顧客データの社外持ち出しを禁止する。検証目的であっても、本番の顧客データをローカル環境へ複製しない。
個人情報を含むデータは、アクセス権限を持つ担当者のみが取り扱う。

## 生成AI・LLMの業務利用

顧客の**個人情報・機密情報を外部のLLMに入力してはならない**。
業務での生成AI利用は、社内で**承認済みのツール・モデル**に限る。
コード補助（Claude Code / GitHub Copilot 等）の利用は許可するが、生成物もレビュー対象とする。
